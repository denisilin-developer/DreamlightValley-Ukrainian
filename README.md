# 🇺🇦 Disney Dreamlight Valley — українська локалізація

Повний фанатський переклад **Disney Dreamlight Valley** українською: інтерфейс, предмети, завдання, події та всі діалоги — понад **144 000 рядків**.

Версія 2 (вересень 2026) — це повністю переписаний переклад, а не машинний:

- назви місць, предметів і подій локалізовано за єдиним глосарієм (Вічноказка, Ранчо Квітучих Бажань, Дрімлайт, Острів Вічності…);
- персонажі — з українськими іменами з дубляжу (Попелюшка, Дзвіночок, Базз Рятівник, Аїд, ВОЛЛ·І, Угі-Бугі…);
- героїні говорять у жіночому роді, до гравця всюди звертаються на «ти»;
- жарти, каламбури й віршики адаптовано українською, а не перекладено дослівно.

## 🚀 Встановлення

1. Завантажте архів `LocDB_en-US.zip` з [останнього релізу](https://github.com/denisilin-developer/DreamlightValley-Ukrainian/releases/latest).
2. Відкрийте теку з грою, наприклад:
   ```text
   D:\Steam\steamapps\common\Disney Dreamlight Valley\ddv_Data\StreamingAssets\Localization\LocDB_en-US
   ```
3. Зробіть резервну копію цієї теки, потім замініть її вміст файлами з архіву.
4. Запустіть гру з англійською мовою інтерфейсу — текст буде українським.

Після оновлення гри Steam може повернути англійські файли — просто встановіть переклад знову. Якщо в новій версії з'явився новий текст, він показуватиметься англійською, доки переклад не оновлять.

## 🛠 Для перекладачів

- `tools/` — скрипти на Python 3 без залежностей:
  - `locbin.py` — читання й запис файлів `.locbin` (protobuf `repeated 1 {1: ключ, 2: текст}`), побайтово без втрат;
  - `merge.py` — накладає наявний переклад на свіжі англійські файли нової версії гри й складає список нових/змінених рядків;
  - `prepare.py`, `make_batches.py` — розбивають роботу на пакети; `check.py`, `check_review.py`, `align.py`, `audit.py` — перевірки (розмітка, плейсхолдери, «ти/ви», рід мовця, зсув рядків, однаковість назв);
  - `apply.py`, `apply_rv.py`, `build_items.py`, `final_unify.py` — збирання готових файлів гри.
- `glossary/` — глосарій (1 240 термінів + доповнення), принципи найменування та інструкція для перекладачів.
